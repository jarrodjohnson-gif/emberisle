## 1. SeatPublicGains.tsx Audit (pre-#1547 main)

Section 1 is written against pre-#1547 main before the seat gains rebuild.
`SeatPublicGains` renders public roll and trade goods deltas under player seats.
The component renders into the DOM through React portals attached to seat cards.

### ARIA Attributes and Semantics
- **Role:** The container span specifies `role="status"`.
- ARIA specifications assign `role="status"` an implicit polite live region.
- **aria-label:** The tag carries `aria-label={`${name}: ${label}`}`.
- Example output includes `"Joshua: +2 Wheat"` and `"Joshua: +1 Wood, −1 Wheat"`.
- **aria-hidden:** Inner pill spans set `aria-hidden="true"`.
- This prevents screen readers from announcing fragmented icons and signed numerals twice.
- **aria-live:** `role="status"` provides implicit `aria-live="polite"` without interrupting user input.

### TabIndex and Focus Behavior
- The component sets no `tabIndex`.
- The container has `pointer-events: none` in CSS.
- The cue never captures pointer clicks or keyboard focus.
- Seat buttons use `position: relative` and `z-index: 1`.
- Keyboard users reach and activate underlying seat buttons without interference.

### Motion and Lifetime
- The cue holds for 2.5 seconds before fading.
- CSS slide and opacity transitions disable under `prefers-reduced-motion: reduce`.
- Under reduced motion, the tag renders statically without animation.

## 2. TradePanel.tsx Audit (merged PR #1540)

`TradePanel` provides a modal dialog for table offers and bank exchanges.
It was rebuilt in PR #1540 with stacked Give and Get sections.

### Dialog Semantics and Landmarks
- The dialog container sets `role="dialog"` and `aria-modal="true"`.
- `aria-labelledby="trade-title"` points to the `Trade` heading.
- The scrollable goods list has `role="region"` and `tabIndex={0}`.
- The region uses `aria-labelledby="trade-goods-title"` with visually hidden heading text.
- Subsections use `aria-labelledby` linking to `"Give"` and `"Get"` headings.
- The bank is a single button with `aria-describedby="trade-bank-quote"`.

### Focus Management and Focus Trapping
- `useFocusTrap` manages modal focus lifecycle.
- Focus lands initially on the Close button when the panel opens.
- Tab and Shift-Tab cycle strictly through focusable elements inside the dialog.
- Pressing Escape closes the panel, plays `ui_back`, and restores focus cleanly.
- When an offered count returns to zero, the minus button unmounts.
- Focus transfers cleanly to adjacent interactive controls.

### Form Controls and Labels
- Stepper buttons use `${name}` in their `aria-label` tags.
- `<output>` elements are `sr-only` for screen reader announcements.
- Visible count numbers render inside `aria-hidden` badge containers.
- Needs in `SeatNeeds.tsx` render as seat-colour dots rather than toggle buttons.
- The panel presents the trade proposal sentence and Ask-the-table flow clearly.

### Focus-Visible Outlines
- `trade-panel.css` defines `2px solid var(--ink)` outlines on the scroll region and details.
- Outline offsets ensure rings remain visible against light card backgrounds.

### Keyboard Navigation Validation
`scripts/trade-tabs-prove.mjs` validated keyboard flows across four viewports.
The suite verified:
1. Close button receives initial modal focus.
2. Tab key navigates into the scrollable goods region.
3. Stepper controls allow full keyboard drafting without mouse interaction.
4. Unmounted minus controls return focus cleanly.
5. Focus wraps inside the dialog without leaking.
6. Escape key dismisses the dialog cleanly.
