# Emberisle

A living 3D island settler board for friends. Hex land, wandering sheep, rocking harbor boats, and a wayfarer who crosses the wastes.

## Play

Open the app, tap **Play versus the isle**. Drag to orbit. Tap glowing corners to settle, then lay a path. First to 10 points wins.

- **Play versus the isle** — you plus three bots
- **Four seats, one table** — hotseat
- Host / join codes are the start of friend tables

## Rules (base game)

19 hexes, 2–12 number tokens (no 7), robber on 7, distance rule on outposts, 4:1 bank (3:1 / 2:1 at ports), development deck, longest road and largest army.

## Stack

React, Three.js, Zustand. No account. Run locally and tunnel if you want friends on the same table.
