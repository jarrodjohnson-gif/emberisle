# Emberisle

A living 3D island settler board for friends.

**Visual north star:** white-slab hex dioramas (see `docs/VISION.md` and `public/refs/hex-north-star.jpg`).

## Play

Tap **Play versus the isle**. Drag to orbit. Tap glowing corners to settle. First to 10 points wins.

- Versus the isle — you plus three bots
- Four seats, one table — hotseat
- Host / join — friend tables (P2P, in progress)

## Rules

19 hexes, tokens 2–12 (no 7), robber on 7, distance rule, 4:1 bank (ports 3:1 / 2:1), fortunes, longest path, largest army.

## Stack

React, Three.js, Zustand. No accounts. Host locally and tunnel for friends.
